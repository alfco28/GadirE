# <div align="center">GadirE: Mapa Interactivo de la Universidad de Cádiz</div>

> *GadirE* es una iniciativa del Consejo de Estudiantes para ofrecer un mapa interactivo de la Universidad de Cádiz al completo. Este mapa está hecho por estudiantes y está optimizado para ser usado desde un navegador de escritorio hasta una aplicación móvil.

🔗 **[Accede al mapa aquí](https://ceuca.uca.es/wp-content/uploads/2025/12/CEUCAtlas.html)**

---

## 📱 Aplicación

La aplicación está disponible para cualquier dispositivo y sistema operativo para los que exista un navegador compatible con **Progressive Web Apps (PWA)**, es decir, para casi cualquier dispositivo.

### 🛠️ Instalación

1. Abre el mapa a través del enlace proporcionado al final de esta página.
2. Pulsa el botón de **"más opciones"** de tu navegador.
3. Elige la opción **"Añadir a pantalla de inicio"** o similar.
4. Pulsa **"Aceptar"**, ¡y listo! La aplicación estará lista para funcionar.

### ⚠️ Consideraciones

- La aplicación **no funciona sin conexión**.
- El CEUCA **no puede acceder a tu ubicación** de ninguna forma.
- La aplicación **se actualiza automáticamente**.
- La aplicación es **mucho más ligera** que la mayoría de aplicaciones disponibles en las tiendas de aplicaciones habituales.
